# hosh

## عامل جاروبرقی واکنشی ساده (Simple Reflex Vacuum Agent)

شبیه‌سازی یک عامل واکنشی ساده در محیط ۲×۲ که هدفش **تمیز کردن خانه‌های کثیف** است.

### قانون واکنشی

- اگر خانه **کثیف** است → جارو بکش (`SUCK`)
- اگر خانه **تمیز** است → به خانه بعدی حرکت کن

### اجرا

```bash
python vacuum_agent.py
```

### ساختار

| نقش | کلاس |
|---|---|
| محیط ۲×۲ با خانه‌های کثیف/تمیز | `Environment2x2` |
| عامل واکنشی ساده | `SimpleReflexVacuumAgent` |
| حلقه اجرا | `run_agent()` |
